# Security Policy

AgentNet is early-stage software. Security-sensitive reports should be handled
privately so maintainers can assess impact before public disclosure.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues. Send a private report
to the maintainers with a description, reproduction steps, affected versions,
and any known mitigations.

Maintainers will acknowledge valid reports, investigate impact, and coordinate
fixes and disclosure timing where appropriate.
