# Code of Conduct

AgentNet contributors are expected to keep project spaces professional,
constructive, and focused on the work.

## Our Standards

Examples of behavior that contributes to a healthy project include:

- Using clear, respectful language.
- Welcoming different levels of experience.
- Giving and receiving technical feedback constructively.
- Focusing criticism on ideas, designs, and code.

## Unacceptable Behavior

Unacceptable behavior includes harassment, intimidation, discriminatory
language, personal attacks, sustained disruption, or publishing another
person's private information without permission.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict access for
behavior that violates this code of conduct. Reports should include relevant
context and will be reviewed as promptly and fairly as possible.
